# **App Name**: ZoomCutDashboard

## Core Features:

- Subscriber List: Display all subscribers in a sortable, paginated table.
- Search and Filter: Search and filter subscribers by name, email, status, or plan.
- Subscriber Details: View detailed information for individual subscribers (plan, subscription date, payment history, etc.).
- Edit Subscriber: Edit subscriber details, including subscription plan and status. These edits will not actually modify the subscriber data, but will serve to illustrate the feature for demo purposes.
- Subscription Insights: Tool to Generate insights and predictions about subscription trends using past user data. LLM to analyze factors that affect churn.
- Key Metrics Dashboard: Display key metrics such as total subscribers, MRR (Monthly Recurring Revenue), churn rate, and average subscription length.

## Style Guidelines:

- Primary color: Dark red (#EB1818) for a professional, consistent tone.
- Background color: Very light red (#111111) clean backdrop.
- Accent color: Muted red-purple (#991048) for subtle visual interest and to highlight important elements.
- Body and headline font: 'Inter' sans-serif for a modern and clean UI.
- Use simple, outlined icons to represent actions and categories.
- Employ a grid-based layout for consistent spacing and alignment.
